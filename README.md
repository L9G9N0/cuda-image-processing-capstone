# CUDA-Accelerated Image Processing: Grayscale and Sobel Edge Detection

## Project purpose

This project implements a small GPU image-processing pipeline using NVIDIA CUDA. It converts an RGB image to grayscale and then detects edges with the Sobel operator. The work demonstrates data-parallel image processing, CUDA device memory, two-dimensional thread/block indexing, kernel launches, GPU timing, and CPU/GPU result validation.

## GPU techniques

- **Global device memory:** RGB input, grayscale output, and edge output are allocated with `cudaMalloc`.
- **Parallel execution:** grayscale conversion assigns one CUDA thread to each pixel.
- **2D launch geometry:** Sobel edge detection maps CUDA thread coordinates to image coordinates.
- **Kernel timing:** CUDA events measure the GPU kernel pipeline, excluding host-to-device and device-to-host copies.
- **Correctness validation:** CPU implementations calculate reference outputs. The program reports the number of mismatched grayscale and edge pixels.

The Sobel operator estimates horizontal and vertical intensity changes using 3x3 convolution masks. The edge magnitude is approximated by `abs(Gx) + abs(Gy)` and clamped to the 8-bit range.

## Requirements

- NVIDIA GPU with a supported CUDA-capable driver.
- CUDA Toolkit with `nvcc`.
- C++17-capable host compiler supported by the installed CUDA Toolkit.
- Python 3 (only for deterministic input-image generation).
- GNU Make.

## Build

```bash
make
```

## Run

Generate a deterministic 1024x768 PPM input and run both GPU kernels:

```bash
python3 generate_input.py --width 1024 --height 768 --output input.ppm
./cuda_image_capstone --input input.ppm --output result --block 16
```

Run with a larger image:

```bash
python3 generate_input.py --width 1920 --height 1080 --output input_large.ppm
./cuda_image_capstone --input input_large.ppm --output result_large --block 16
```

Or run the full reproducible workflow:

```bash
chmod +x run.sh
./run.sh
```

CLI arguments:
- `--input`: input binary PPM (P6) image.
- `--output`: prefix for generated output files.
- `--block`: Sobel block width and height, from 1 to 32.

## Outputs and execution evidence

Each run creates:
- `<prefix>_grayscale.ppm`: grayscale image.
- `<prefix>_sobel.ppm`: Sobel edge map.
- `<prefix>_timings.csv`: image dimensions, pixel count, block size, GPU kernel time in milliseconds, and CPU/GPU mismatch count.

A successful correctness check reports `CPU/GPU validation mismatches: 0`. Commit the actual generated PPM images, CSV files, and terminal output or screenshots from your CUDA run to the repository. Do not fabricate timing values or screenshots.

## Limitations

The input format is binary RGB PPM (P6), with maximum channel value 255. The current implementation uses global device memory for image data; shared-memory tiling is a possible optimization for the Sobel neighborhood operation. Performance depends on GPU model, CUDA version, image dimensions, and block size.
